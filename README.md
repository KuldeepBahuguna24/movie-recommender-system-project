#  🎬Movie Recommendation System  
#  🚀Features  
-  🎯 Personalized movie recommendations  
- 🧠 Content-based filtering using ML
- 🔍 Search movies by title
- 📊 Cosine similarity for matching movies
- 🔢 TF-IDF vectorization for text processing
- ⚡ Fast and efficient recommendation engine
- 📁 Handles large movie datasets
- 📝 Data preprocessing and cleaning
- 📌 Displays top similar movies
#  ⚙️ How It Works
- 📂 Load and preprocess movie dataset
- 🧹 Clean and organize data
- 🧠 Extract features (genre, cast, keywords)
- 🔢 Convert text into vectors using TF-IDF
- 📊 Compute similarity matrix using cosine similarity
- 🔍 User enters a movie name
- 🎯 System finds closest matching movies
- 📜 Returns top recommended movies
- ⚡ Ensures fast results using precomputed data
